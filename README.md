# SimuFactory- Simulador de Produção Industrial
Simulador de uma linha de produção industrial desenvolvido somente com Python e sua biblioteca padrão.

## Funcionalidades
- Simulação de inspeção de peças
- Detecção virtual de produtos defeituosos
- Contadores de produção aprovada e reprovada
- Configuração da quantidade de matéria-prima e da taxa esperada de defeitos
- Relatório com eficiência de qualidade e alertas

 ## Requisitos
- Python 3.10 ou superior
- Nenhuma biblioteca externa

## Conceitos praticados
Variáveis, funções, condicionais, laços de repetição, validação de entradas, dicionários, listas, números aleatórios e organização de um programa em módulos lógicos.

## Como executar
1. Baixe ou clone este repositório.
2. Abra o terminal na pasta do projeto.
3. Execute:

```bash
python simufactory.py
```

Em alguns sistemas, o comando pode ser `python3 simufactory.py`.
